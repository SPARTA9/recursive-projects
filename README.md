A collection of Python programs developed while studying A-level Computer Science, focusing on recursion and iterative programming techniques.

Projects

1. Vowel Counting — Q31.py

Compares iterative and recursive approaches to counting vowels in a string.

Concepts covered:

Iteration using for loops

Recursive functions

Base cases and recursive calls

String indexing and slicing

Returning values from functions

2. Recursive and Iterative Functions — Q32.py

Explores recursive and iterative implementations of a function that changes the value of x toward y, prints intermediate sums, and returns a result.

Concepts covered:

Recursive function calls

Base cases

Iteration using while loops

Conditional statements

Return values and integer arithmetic
